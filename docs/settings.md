# Конфигурационный файл
По умолчанию настройки программы находятся в файле `amproxy.ini`.

Указать местоположение конфигурационного файла можно:
* в командной строке: `amproxy.py -c /path/to/config`
* в переменной окружения: `AMPROXY_CONFIG=/path/to/config`

Поиск конфиг-файла производится в следующих местах:
* системный:
  * Linux/MacOS: `/etc/amproxy/`
  * Windows: `C:\ProgramData\amproxy\`
* пользовательский:
  * текущий рабочий каталог
  * каталог, где лежит сам скрипт
  * в домашнем каталоге:
    * Linux/MacOS: `~/.amproxy/`
    * Windows: `C:\Users\Имя\AppData\Local\amproxy\`

Если при старте программа не обнаружит конфиг-файл, в домашнем
каталоге будет создан дефолтный конфиг с единственным пустым разделом
`[DEFAULT]`.

Если параметр `DYNAMIC_CONFIG` установлен в 1, программа проверяет
наличие в конфиге раздела с именем провайдера, и если он отсутствует -
добавляет его.

Формат конфиг-файла - ini. Все настройки разделены на разделы. Имена
разделов чувствительны к регистру (case-sensitive). Имена параметров -
не зависят от регистра, в процессе чтения файла все имена параметров
приводятся к верхнему регистру. Значения могут быть только числами и
строками. Булевые значения отсутствуют, вместо них используется 0/1.

Комментарии в конфиге начинаются с точки с запятой `;` или символа `#`.

При чтении конфига программа всегда считывает настройки из раздела
`[DEFAULT]`. Можно дополнительно указать раздел из которого будут
браться настройки в командной строке: `amproxy.py -s section`

Если параметр `DYNAMIC_CONFIG` установлен в 1, также считываются
настройки из раздела с именем провайдера.

# Основные параметры
* `HOST` - по умолчанию `127.0.0.1` - слушать только локальный
интерфейс. Если необходимо, чтобы прокси слушал на всех интерфейсах,
  укажите `0.0.0.0`.
* `PORT` - по умолчанию `8888` - порт на котором слушает прокси.
* `USER_PASS` - учетные данные для аутентификации (логин:пароль). Если
пустая строка - не использовать аутентификацию.
* `DYNAMIC_CONFIG` - динамическое изменение настроек и стратегий
(кэша) при смене провайдера. По умолчанию `1`.
* `LOG_LEVEL` - уровень логирования:
  * `ERROR` - выводить только сообщения об ошибках
  * `INFO` - средний уровень
  * `DEBUG` - вывод отладочной информации
  * Если необходимо полностью отключить логирование, установите уровень в `CRITICAL`.
* `LOG_FILE` - имя лог-файла. По умолчанию `amproxy.log`. Размер
лог-файла 100 КБ, хранится 4 старые копии. Если необходимо отключить
вывод лога в файл - укажите пустую строку: `log_file=` в конфиг-файле.
