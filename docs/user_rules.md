# Пользовательский файл стратегий
Для ручного указания стратегий можно использовать пользовательский файл стратегий.
По умолчанию файл `user-rules.txt` в том же каталоге, что и программа.

Для указания стратегии:
`<домен> <стратегия (набор параметров для ciadpi)>`

Дополнительно можно указать:

* соединение устанавливается напрямую:
`<домен> DIRECT`

* домен блокируется:
`<домен> BLOCK`

* использовать внешний прокси-сервер:
`<домен> EXTERN <адрес прокси>`

Можно использовать комментарии: текст от знака `#` до конца строки игнорируется.
Можно использовать wildcard.

Пример:

```
*.youtube.com -a1 -o1 # использовать стратегию "-a1 -o1" для youtube.com и всех его поддоменов
static.cloudflareinsights.com DIRECT # соединяем напрямую
mtalk.google.com BLOCK # блокируем соединение
*.telegram.org EXTERN socks5://localhost # используем внешний прокси-сервер
```

Пользовательские стратегии имеют приоритет перед найденными программой.
